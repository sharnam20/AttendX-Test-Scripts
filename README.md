
# AttendX-Test-Scripts

## Project Description
This repository contains sample test scripts
for a student attendance application called AttendX.

## Files

### login_test.py
Checks that the username and password inputs
are not empty.

### attendance_test.py
Checks that a student ID and a valid attendance
status are provided.

## Technologies Used
- Python
- Git
- GitHub
- Visual Studio Code

## Purpose
To demonstrate version control of test scripts
using Git and GitHub.
Repository updated directly on GitHub
